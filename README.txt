NIRC 빛달 기록찾기 v0.3 — 배포 전 시제품

변경점: SPCT 등록 대회 선택 + 선수 이름 입력 시 searchResultsName 쿼리로 공식 검색결과 페이지 직접 연결.
테스트 예: 김유진 / 제15회 부여 굿뜨래 마라톤 / 풀코스. 공식 결과 목록에서 종목·배번호(45538)를 확인하고 개인 기록 선택.
주의: 사이트 자동 검색 실제 작동은 사용자의 브라우저에서 검증 필요. 공식 기록 자동 수집 및 이미지 자동 생성 미지원.
스마트칩 및 MyResult는 아직 단순 링크 연결. 기존 v0.2 로컬 저장 키(nirc-*) 유지.

배포 상태: ZIP 제작만 완료, Vercel 배포하지 않음.
기존 앱 업데이트인 경우 반드시 기존 Vercel projectId, Production URL, PWA manifest, 저장구조를 확인하고 동일 프로젝트에 배포. 신규 프로젝트 생성 금지.
이번 ZIP은 정적 index.html 파일이며 manifest 및 서비스워커는 포함하지 않음. 기존 PWA를 덮어쓸 경우 기존 설정을 보존하며 병합해야 함.
사용자 데이터: 브라우저 localStorage 사용. 삭제하거나 초기화하지 말 것.
