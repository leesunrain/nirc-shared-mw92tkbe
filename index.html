② 참가대회 찾기

SPCT 등록 대회에서는 선수 이름을 검색주소에 자동 반영합니다. 결과 목록에서 종목과 배번호를 확인해 선수를 선택하세요. 스마트칩은 공식 홈페이지에서 대회를 선택하여 검색합니다. MyResult는 등록된 대회의 배번호를 입력하면 개인 기록으로 바로 이동합니다. 공식 기록을 앱으로 자동 수집하지는 않습니다.

③ 최근 검색 기록

공식 기록조회 버튼을 누르면 선수·대회·종목·조회일과 연결주소를 이 기기에 자동 보관합니다. 완주기록은 자동으로 가져오지 않습니다.

④ 기록 보관 (선택)

기록 입력 예: 03:08:52 / 3:08:52 / 3 08 52 / 30852 / 030852 / 3시간 8분 52초. 저장 시 03:08:52로 통일됩니다.

공식 사이트에서 확인한 기록을 직접 입력해 저장합니다. 이 기기의 브라우저에만 보관되며 다른 사람과 자동 동기화되지 않습니다.

사용 안내

이 버전은 배포 전 시제품 v0.7입니다. 검색 이력은 조회 버튼을 누를 때 저장됩니다. SPCT 이름 검색주소 연결은 제공된 실제 URL 형식을 사용하며, 사이트 측 변경 시 작동하지 않을 수 있습니다. 외부 사이트의 기록을 자동 수집하거나 기록증 이미지를 자동 생성하지 않습니다. 이미지가 필요하면 공식 기록증을 해당 사이트에서 저장하세요. 저장한 선수·기록은 브라우저 데이터를 지우면 사라질 수 있습니다.
